P1 · Le paysage

📚 Fiche d’exercices – Arts – CE1 – Le paysage *(période 1 – école française)*

Durée : 45 min – 1 h Matériel : crayons de couleur, feutres, gomme, feuille blanche A4, règle (facultative), tableau ou affiche « les éléments du paysage ». ---

1️⃣ VERSION SOUTIEN – (étayé, plus simple)

🎯 Objectifs

- Identifier les trois grands éléments d’un paysage : le ciel, la terre (sol, collines, arbres) et l’eau (rivière, lac, mer). - Utiliser trois couleurs de base (bleu, vert, marron) pour les représenter. - Décrire oralement ce qu’il a dessiné.

📋 Consignes

1. Observe l’image du paysage ci‑dessous (affichée au tableau). 2. Colorie chaque partie du paysage avec la bonne couleur : - Ciel → bleu clair - Terre/arbres → vert ou marron (selon la partie) - Eau → bleu foncé 3. Écris sous ton dessin le mot qui correspond à chaque partie (ciel, terre, eau). > Astuce : Si tu ne sais pas où mettre la couleur, regarde la légende au tableau.

🖍️ Exercice

| Étape | Action | Espace pour le dessin | |------|--------|------------------------| | 1 | Trace légèrement le contour du paysage (ciel en haut, terre au milieu, eau en bas). | | | 2 | Colorie le ciel en bleu clair. | | | 3 | Colorie la terre (herbe, arbres) en vert ou marron. | | | 4 | Colorie l’eau en bleu foncé. | | | 5 | Écris les mots ciel – terre – eau sous chaque zone. | | ---

✅ Corrigé – Soutien

| Élément | Couleur attendue | Mot à écrire | |---------|------------------|--------------| | Ciel | Bleu clair | ciel | | Terre | Vert ou marron | terre | | Eau | Bleu foncé | eau | > Remarque pour l’enseignante : Vérifiez que chaque élève a bien séparé les trois zones et que les mots sont lisibles. ---

2️⃣ VERSION STANDARD – (niveau attendu)

🎯 Objectifs

- Reconnaître cinq éléments du paysage : ciel, soleil, terre, végétation, eau. - Utiliser au moins cinq couleurs différentes. - Rédiger une courte phrase descriptive (5‑7 mots).

📋 Consignes

1. Observe le paysage sur la fiche (photo d’un petit village). 2. Dessine le paysage sur ta feuille en respectant les proportions (ciel en haut, terre au centre, eau en bas). 3. Colorie chaque élément avec la couleur indiquée : - Ciel → bleu ciel - Soleil → jaune - Terre (sol, rochers) → marron - Végétation (arbres, herbes) → vert - Eau → bleu marine 4. Écris sous ton dessin une phrase qui décrit le paysage (ex. : « Le soleil brille sur la rivière »).
