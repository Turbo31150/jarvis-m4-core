🧩 Adaptations par profil d'élève

10 profils — aménagements pédagogiques prêts à appliquer (dys, TDAH, TSA, allophone, HPI, PPRE…). Repère le profil, applique les aménagements. Ctrl+P pour joindre à un PPRE/PAP.

Allophone (EANA — élève nouvellement arrivé)

🎯 Besoins : Français en cours d'acquisition, lexique scolaire limité, culture scolaire différente.

🛠️ Aménagements : Appui visuel systématique (images, gestes) ; lexique bilingue ; tutorat par un pair ; simplifier la langue des consignes sans appauvrir le contenu ; valoriser la langue d'origine.

🎒 Matériel : Imagiers thématiques, dictionnaire bilingue/traducteur, étiquettes-mots, supports visuels, cahier de sons.

📝 Évaluation : Évaluer les compétences non-langagières à part ; consignes illustrées ; oral privilégié ; ne pas sanctionner la langue.

Difficulté scolaire (PPRE / élève fragile)

🎯 Besoins : Acquis fragiles, lenteur, faible estime de soi, découragement.

🛠️ Aménagements : Objectifs prioritaires ciblés, étayage rapproché, réussite garantie au départ, valorisation, aide des pairs, quantité réduite mais exigence maintenue.

🎒 Matériel : Fiches de soutien (niveau Soutien de la banque !), affichages d'aide, sous-main, cahier de réussites.

📝 Évaluation : Évaluer les objectifs prioritaires ; barème adapté ; valoriser les progrès ; évaluation positive.

Dyscalculie

🎯 Besoins : Sens du nombre fragile, mémorisation des faits numériques difficile, procédures instables.

🛠️ Aménagements : Manipulation systématique avant l'abstrait ; autoriser table de multiplication et bandes numériques ; décomposer les problèmes ; verbaliser les étapes.

🎒 Matériel : Jetons, réglettes Cuisenaire, bande numérique, boulier, table de Pythagore, calculatrice si PAP.

📝 Évaluation : Évaluer le raisonnement, pas le calcul mental ; problèmes lus ; outils autorisés.

Dyslexie / Dysorthographie

🎯 Besoins : Décodage lent et coûteux, fatigue en lecture, orthographe instable.

🛠️ Aménagements : Textes aérés (police Arial/OpenDyslexic 14, interligne 1.5) ; lire les consignes à voix haute ; ne pas faire lire à voix haute devant la classe sans accord ; segmenter les tâches ; valoriser l'oral.

🎒 Matériel : Règle-cache / fenêtre de lecture, surligneurs, dictée à trous, cartes-sons, ordinateur avec correcteur si PAP.

📝 Évaluation : Ne pas pénaliser l'orthographe hors dictée ; barème allégé ; tiers-temps ; consigne relue.

Dyspraxie

🎯 Besoins : Geste moteur et coordination difficiles, écriture lente/illisible, repérage spatial fragile.

🛠️ Aménagements : Limiter la copie (fournir les traces écrites) ; agrandir les supports ; cases/lignes repères ; privilégier le clavier ; éviter les tableaux à double entrée complexes.

🎒 Matériel : Cahier à gros carreaux/lignes Seyès agrandies, guide-doigt, ciseaux adaptés, plan incliné, gabarits.

📝 Évaluation : Évaluer les connaissances, pas le geste ; oral ou QCM ; ne pas noter le soin ; tiers-temps.

Déficience visuelle

🎯 Besoins : Fatigue visuelle, accès aux supports écrits limité.

🛠️ Aménagements : Agrandir (A3, police 18-24), fort contraste, placer près du tableau, verbaliser ce qui est écrit, éviter le bleu/vert peu contrasté.

🎒 Matériel : Supports agrandis, contraste renforcé, loupe, pupitre, matériel tactile, plage braille si besoin.

📝 Évaluation : Supports adaptés fournis ; tiers-temps ; oral possible ; consignes verbalisées.

HPI / élève à haut potentiel

🎯 Besoins : Rapidité, besoin de sens et de défi, ennui possible, perfectionnisme.

🛠️ Aménagements : Approfondissement et enrichissement (pas plus du même) ; projets autonomes ; tutorat d'un pair ; questions ouvertes ; droit à l'erreur travaillé.

🎒 Matériel : Fichiers d'approfondissement, défis logiques, projets de recherche, accès documentaire, jeux de stratégie.

📝 Évaluation : Tâches complexes et ouvertes ; valoriser la démarche ; éviter la répétition.

TDAH (attention / hyperactivité)

🎯 Besoins : Attention labile, impulsivité, difficulté à rester en place et à s'organiser.

🛠️ Aménagements : Consignes courtes et une à la fois ; place au calme, près de l'enseignante ; pauses motrices ; time-timer visible ; renforcement positif immédiat ; routines claires.

🎒 Matériel : Time-timer, sablier, casque anti-bruit, sous-main avec étapes, balle anti-stress, ceinture lestée.

📝 Évaluation : Fractionner l'évaluation ; temps supplémentaire ; environnement calme ; consignes rappelées.

TSA (trouble du spectre autistique)

🎯 Besoins : Besoin de prévisibilité, sensibilité sensorielle, communication et implicite difficiles.

🛠️ Aménagements : Emploi du temps visuel (pictos), anticiper les changements, consignes explicites et littérales, espace refuge, éviter le second degré, séquentialiser.

🎒 Matériel : Pictogrammes/PECS, emploi du temps visuel, timer, casque anti-bruit, coin calme, scénarios sociaux.

📝 Évaluation : Consignes explicites, éviter les doubles sens, format habituel, temps adapté, valoriser les intérêts spécifiques.

Trouble du langage oral (dysphasie)

🎯 Besoins : Expression et/ou compréhension orale altérées, lexique et syntaxe fragiles.

🛠️ Aménagements : Phrases courtes, débit lent, reformulation, appui gestuel et visuel ; laisser le temps de répondre ; ne pas finir les phrases à sa place.

🎒 Matériel : Pictogrammes, Makaton/gestes, imagiers, supports visuels de consigne, coin langage.

📝 Évaluation : Privilégier le pointage/QCM ; ne pas évaluer la forme orale ; temps de latence accepté.
