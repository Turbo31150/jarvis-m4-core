Cible

Développeurs, makers et enseignants self-hosters qui utilisent Claude Code et veulent des garde-fous concrets : anti-surchauffe, anti-boucle, filtre destructif, cadrage.

Un assistant de code sans garde-fous peut lancer des boucles, exécuter des commandes destructrices ou faire surchauffer la machine ; on veut un cadre prêt à l'emploi, pas à écrire soi-même.

Un ensemble de hooks fail-safe qui cadrent Claude Code : garde thermique matérielle, anti-boucle Stop, filtre des commandes destructrices, dédup vocale — plus les briques Stop-Cycles, Checkpoint sécurisé et Snapshot avant test.
