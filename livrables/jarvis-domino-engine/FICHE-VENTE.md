## Description (prête à coller sur Gumroad)
Vous perdez des heures sur des tâches répétitives — trier, relancer, générer,
publier, sauvegarder — et les outils no-code du marché vous enferment dans des
abonnements mensuels tout en aspirant vos données vers leurs serveurs. Pour
beaucoup de métiers (santé, éducation, juridique, indépendants), envoyer ces
données dans le cloud est inacceptable.

AlkymIA Flow est un moteur d'automatisation qui fonctionne entièrement
sur votre machine. Un « domino » est une brique d'action prête à l'emploi ; une
chaîne de dominos forme un « pipeline » qui exécute une tâche complète. Livré
avec 835 pipelines et 5256 dominos compilés. Vous branchez, vous lancez, ça
tourne.
