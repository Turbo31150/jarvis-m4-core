# MCP API Key Rotation

## Overview

A leaked key in a config file is rarely the only copy. Rotation requires finding EVERY source (configs, env, Docker, cron, git, conversation jsonl) AND revoking the old one server-side. Forgetting any single source = the leak persists.

**Core principle: Old key revoked server-side is the only proof of rotation. Until you've TESTED the old key returns 401, the rotation is not complete.**

## The Six Surfaces Every Key Lives On

| Surface | How to find |
|---|---|
| 1. Active config files | `grep -rF "<old_key_prefix>" ~/.claude*/ ~/.config/ ~/jarvis/ ~/.bashrc ~/.profile ~/.zshrc` |
| 2. Project `.env` files | `find ~ -name ".env*" -not -path "*/node_modules/*" 2>/dev/null \| xargs grep -lF "<prefix>" 2>/dev/null` |
| 3. Docker containers | `docker ps -q \| xargs -I{} docker inspect {} 2>/dev/null \| grep -F "<prefix>"` |
| 4. Docker compose files (the REAL source) | `find ~ -name "docker-compose*.y*ml" 2>/dev/null \| xargs grep -lF "<prefix>" 2>/dev/null` |
| 5. Cron jobs | `crontab -l ; find /etc/cron* -type f 2>/dev/null \| xargs grep -lF "<prefix>" 2>/dev/null` |
| 6. Git history | `git -C ~/jarvis log -S "<prefix>" --all --oneline ; git -C ~/jarvis-* log -S "<prefix>" --all --oneline` |
| 7. Conversation jsonl | `grep -rlF "<prefix>" ~/.claude/projects/ 2>/dev/null` |

If you don't check all 7, the leak persists. No shortcut.
