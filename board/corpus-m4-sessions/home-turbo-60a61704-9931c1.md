# run-jarvis-demarrage

One bash driver that runs the verified JARVIS startup smoke: system snapshot →
SQLite WAL warm-up → agent counts → git → monitoring procs → cluster ping. It's
the reproducible core of the heavier `jarvis-turbo:demarrage` plugin skill, with
the **correct SQL table names** baked in (the plugin's prose references tables
that don't exist — see Gotchas). Paths relative to repo root `/home/turbo/jarvis`.

Driver: **`.claude/skills/run-jarvis-demarrage/demarrage.sh`**.

## Run (agent path)
```bash
cd /home/turbo/jarvis
bash .claude/skills/run-jarvis-demarrage/demarrage.sh
# or target another DB:
DB=data/jarvis.db bash .claude/skills/run-jarvis-demarrage/demarrage.sh
```
Read-only except `PRAGMA journal_mode=WAL` (persistent + idempotent). Prints a
7-section report; last line is `### démarrage smoke done`.

## What each section checks
| # | Section | Source |
|---|---|---|
| 1 | CPU load / RAM / per-GPU temp+VRAM | `uptime`, `free`, `nvidia-smi` |
| 2 | SQLite WAL + synchronous/cache/temp pragmas + `quick_check` | `sqlite3 data/jarvis.db` |
| 3-4 | Row counts: `jarvis_agent_registry`, `jarvis_agents`, `llm_backends`, `jarvis_cluster_map` | same DB |
| 5 | Branch / HEAD / dirty count / last 3 commits | `git` |
| 6 | Live monitoring PIDs (watchdog, guardian, pulse, gpu_monitor) | `pgrep` |
| 7 | M1/M2 LM Studio `:1234` reachability + M5 ping | `curl`, `ping` |

# run-antigravity-jarvis

Pilote Antigravity (Google agentic IDE, fork Electron de VSCode) sur M1. Antigravity tourne en deux profils parallèles via systemd-user :

- **DEV** — GUI sur `DISPLAY=:0`, data-dir `~/.config/Antigravity`, CDP `127.0.0.1:9001`, expose LAN via socat `0.0.0.0:9002`.
- **PROD** — xvfb-run headless, data-dir `~/.config/Antigravity-Prod` (chargé avec `secrets.env` Mirra + creds M5), CDP `127.0.0.1:9011`, expose LAN via socat `0.0.0.0:9012`.

Le skill **ne crée pas** les services systemd ; il assume qu'ils existent. Il les démarre/arrête, fait du healthcheck CDP, screenshote la GUI, exécute du JS via CDP, et corrige le bug d'écran hors-cadre.

## Prérequis

Services systemd-user attendus (créés hors skill) :

| Unit | Rôle |
|---|---|
| `antigravity-gui.service` | DEV — binaire `~/.local/bin/antigravity --no-sandbox --remote-debugging-port=9001` sur DISPLAY=:0 |
| `antigravity-prod.service` | PROD — `xvfb-run … --user-data-dir=~/.config/Antigravity-Prod --remote-debugging-port=9011` |
| `socat-ag-9002.service` | relay LAN `0.0.0.0:9002 → 127.0.0.1:9001` |
| `socat-ag-9012.service` | relay LAN `0.0.0.0:9012 → 127.0.0.1:9011` |

Binaires requis : `antigravity` (sous `~/.local/bin/`), `wmctrl`, `import` (ImageMagick), `curl`, `systemctl`. Optionnel : `websocket-client` Python ou `wscat` pour `driver.py eval`.
