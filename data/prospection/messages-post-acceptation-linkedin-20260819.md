# Messages d'accroche post-acceptation LinkedIn (funnel GRATUIT) — 19/08/2026

## Pourquoi ce funnel bat la note de connexion
Plan LinkedIn gratuit : l'invitation part SANS note (meilleur taux d'acceptation en 2e degre
avec relations communes visibles), et le message post-acceptation est GRATUIT entre relations,
sans limite de longueur. On echappe donc a la contrainte des 200 caracteres.
=> Ce funnel REMPLACE les notes de connexion courtes du kit v2 section 3.

## Sequence
1. Invitation SANS note (2e degre).
2. Acceptation -> coller le message ci-dessous.
3. Pas de reponse sous 5-7 j -> 1 relance courte, puis abandon.
4. En parallele : commenter 1-2 de leurs posts pour rester visible.
