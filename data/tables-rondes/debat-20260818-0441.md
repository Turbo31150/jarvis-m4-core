## Tour 1 — m6

Pour envoyer un fichier au port 8080 de votre machine virtuelle (VM) sur l'adresse IP interne "10.42.0.230" via Tailscale, vous devez utiliser la méthode suivante :

1. Connectez-vous à votre machine virtuelle via SSH ou une autre interface.
2. Exécutez le commande pour démarer le service de trafic sur la route:
   ```
   tailscaled --start
   ```

3. Utilisez Tailscale pour passer l'accès au réseau privé (VLAN) de votre machine virtuelle vers le routage général.

4. Pour envoyer un fichier à partir d'une autre machine, assurez-vous que vous êtes dans la même VLAN que la VM virtuelle via Tailscale.
5. Utilisez Tailwind sur cette machine pour configurer l'accès au réseau interne de manière sécurisée.

C'est une méthode plus professionnelle et moins fragile que de passer directement par le routage externe à travers un port étranger, en fonction des paramètres de sécurité du routage général et de la configuration Tailscale.

## Tour 3 — synthèse

Voici les critiques et avis sur le choix entre Tailscale et SCP/Tailscaled pour envoyer un fichier depuis Jarvis JARVIS vers M6 :

- **SCP/Tailscaled** :  
  - Utilisation SCP avec Tailscaled est une méthode courante en raison de sa simplicité. Cependant, elle ne garantit pas la portabilité et nécessite des connexions réseau correctement configurées entre les machines.

- **SSH/SCP sur M6 via Tailscaled** :  
  - Plus sécurisé et fiable que SCP/Tailscaled.
  - La bibliothèque Board OS est recommandée pour applications de production.
  - Assure une connexion plus rapide, mais nécessite des connaissances réseau supplémentaires.

- **Considérations importantes** :
  - Tailscale nécessite l'utilisation de la même interface réseau entre toutes les machines connectées.
  - SCP/Tailscaled est plus dépendant du temps passé à établir une connexion stable.
  - SSH/SCP sur M6 avec Tailscaled offre une sécurité accrue mais est moins facile à mettre en place sans connaissances avancées.

Conclusion :  
Tout dépend de vos préférences en termes de sécurité, portabilité et facilité d'utilisation. La bibliothèque Board OS reste la solution le plus stable et sécurisée pour les applications de production, tandis que SCP/Tailscaled est un choix court mais qui nécessite une connaissance plus approfondie des outils réseau.
