# Résumé
Defines the explicitly parallel variants of automovie review, issue campaigns, and benchmark campaigns. Use only when the user explicitly requests a team, parallel, or multi-agent review or campaign. Route review work to review.md, issue campaigns to issue-campaign.md, and benchmark campaigns to benchmark-campaign.md. Self-Review and unqualified review remain solo. Multi-agent issue campaigns parallelize discovery and implementation by default, but an explicit request may limit parallelism to discovery and return implementation to the solo campaign.
