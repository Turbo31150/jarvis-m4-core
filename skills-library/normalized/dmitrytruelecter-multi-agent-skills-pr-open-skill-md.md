# Résumé
Open a pull request from a source branch to a destination branch. Routes by VCS host (GitHub / Bitbucket) derived from the git remote URL, not by the issue tracker. Returns the PR URL on success or an error on failure. Invocation: /dma:pr-open <source-branch> <destination-branch> <title> [workspace-path:<path>] [remote:<name>] [description:<text>].
