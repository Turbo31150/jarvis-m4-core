# Résumé
Harden Kubernetes RBAC by implementing least-privilege Roles and ClusterRoles, auditing RoleBindings, eliminating cluster-admin sprawl, separating service accounts, and integrating external identity providers (OIDC). Use when reviewing or tightening Kubernetes access control, removing excessive ClusterRoleBindings, or hardening service-account permissions against privilege escalation and lateral movement.
