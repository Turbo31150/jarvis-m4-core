**JARVIS M4 core** — orchestration code and configuration for integrating the M4 Windows node into the JARVIS AI cluster. Contains scripts, configs and deployment templates (secrets/models excluded).

## Usage

```powershell
git clone https://github.com/Turbo31150/jarvis-m4-core.git
cd jarvis-m4-core
.\scripts\bootstrap.ps1
```
