⚡ 3-STEP QUICK START:

STEP 1: SET TELEGRAM CREDENTIALS
────────────────────────────────────────────────────────────────────────
Get your bot token from @BotFather on Telegram, then run:

$ export TELEGRAM_BOT_TOKEN='your_bot_token_here'
$ export TELEGRAM_CHAT_ID='your_chat_id_here'

Add to ~/.bashrc to make it permanent:
$ echo 'export TELEGRAM_BOT_TOKEN="..."' >> ~/.bashrc
$ source ~/.bashrc

❓ TROUBLESHOOTING:

Problem: No Telegram alerts
→ Check credentials: echo $TELEGRAM_BOT_TOKEN $TELEGRAM_CHAT_ID
→ Verify: curl https://api.telegram.org/botTOKEN/getMe

Problem: Scripts not running
→ Check cron: crontab -l
→ Test: python3 /home/turbo/automation/scripts/system-monitor.py
→ Logs: tail -20 /home/turbo/automation/logs/*.log

Problem: Cron jobs not executing
→ Check: sudo tail -f /var/log/syslog | grep CRON
→ Test manually: /home/turbo/automation/scripts/linkedin-automation.py
